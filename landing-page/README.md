# Ekklesphere landing page

A standalone marketing landing page for Ekklesphere, kept separate from the main church management application in this repository.

## Run locally

```bash
cd landing-page
npm install
npm run dev
```

The page includes the responsive product hero, gradient image slider, ministry moments slider, feature story, workflow section, impact metrics, testimonial, and demo CTA.

The primary calls-to-action open an interactive demo request modal, and the dashboard quick-add control opens a working action panel with feedback states.
